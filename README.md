# Happy Birthday Jin Guan

Birthday website published with GitHub Pages.

Contains the published photos and captions, interactive candles, and the Love Song music player. Music attempts to play after each refresh; browsers may require an initial click. Wishes are saved on the visitor's device.

The photo workspace runs locally. To refresh the online photos and stories, save them locally, run scripts/build-github-pages.cjs in the original workspace, and upload the regenerated public files.
